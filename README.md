# pairwise-frame-rate-convert

24 帧的素材转成 60 帧后，慢镜头出现果冻和重复帧：帧率转换按固定 2.5 倍插帧，遇到 23.976 的素材累积误差；运动估计只做全局平移，旋转和缩放场景出现撕裂；遮挡区域没有标记，前景和背景被平均成半透明；场景切换处没有检测，跨镜头插出鬼影；插帧顺序在可变帧率时间线上错位，音画不同步；重复帧没有去重，输出体积暴涨；运动矢量在低纹理区域不可靠，天空出现块状；转场帧没有单独处理，淡入淡出被插成双重曝光；输出时间戳按输入帧号换算，长时间运行漂移；批量转码时没有按片段重置状态，上一段的运动矢量污染下一段。video/frame_rate_convert.py 是核心，tests/test_frame_rate_convert.py 15个红。要修的是：精确有理数倍率；旋转缩放估计；遮挡标记；场景切换检测；可变时间线对齐；重复帧去重；低纹理回退；转场保护；时间戳重采样；分段重置。

## 运行

```bash
python -m pytest tests -q
```

初始状态：15 个用例失败。修复实现使全部用例通过，不要修改 `tests/` 下的测试。
